# My Portfolio

## Description
My Portfolio is a personal portfolio website showcasing my projects, skills, and experience as a software engineering student. Built as a fully front-end, responsive site with a clean design, it highlights my technical work, background, and ways to get in touch. The project demonstrates practical front-end development skills, including semantic HTML structure, custom CSS styling, and vanilla JavaScript interactivity.

## Features

* Fully responsive design across desktop, tablet, and mobile
* Sections for About, Skills, Projects, and Contact
* Custom favicon set for browsers, iOS, and Android devices
* Clean, modern UI with smooth navigation
* Optimized static site with no backend dependencies

## How to Use

1. Open `portfolio-1.html` in a browser
2. Browse through the About, Skills, and Projects sections
3. Use the Contact section to get in touch
4. Fully static — no setup or server required
